프로젝트의 방식
\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_
WP-670K 제품 자료에서 확인한 주요 기능과 특징을 브랜드 브리프 JSON에
정리한다. 프로그램은 입력된 제 품 특징, 타깃, 키워드, 톤앤매너 등의
정보를 AI에 전달하여 브랜드 네이밍, 슬로건, 브랜드 스토리와 컬러를
생성하고, 생성 결과를 바탕으로 컬러 팔레트와 로고 시안을 만든다. WP-670K
제품 특징 사전 정리 → 브랜드 브리프 JSON 구성 → 타깃 정보 반영 → AI
브랜드 네이밍 생성 → 슬로건 생성 → 브랜드 스토리 생성 → 컬러 팔레트 생성
→ 로고 시안 생성 → JSON/PNG 저장

1.  제품 분석
    \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_
    WP-670K 제품 자료에서 10단계 수압 조절, 90초 사용 가능한 물 용량,
    치실·마사지 모드, 다양한 전용 팁 등의 주요 특징을 사전에
    확인·정리하고, 이를 브랜드 브리프에 반영하였다. 프로그램에서는
    이렇게 정리된 제품 특징과 타깃·키워드 정보를 AI에 전달하여 브랜드
    기획에 활용할 핵심 가치와 메시지로 해석하도록 구성 하였다. 단순히
    제품 기능을 나열하는 것이 아니라, 각 기능이 타깃 고객에게 어떤
    브랜드 가치로 전달될 수 있는지를 중심으로 브랜드 생성에 활용하였다.

2.  타깃 맞춤형 생성
    \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_
    하나의 WP-670K 제품을 대상으로 타깃 고객을 선택하고, 선택된 고객층에
    적합한 브랜드 아이덴 티티를 생성한다. 예를 들어 20\~30대 직장인,
    가족, 교정 치료 사용자, 임플란트 사용자 등으로 타깃을 설정하고, 각
    타깃에 적합한 브랜드명·슬로건·스토리·컬러·로고를 생성한다. WP-670K는
    팁을 교체하여 가족이 함께 사용할 수 있으며, 제품 자료에서도 교정 및
    임플란트 관 리와 관련된 사용 특성을 별도로 제시하고 있어 타깃별
    테스트에 활용할 수 있다.

3.  단계 간 연계
    \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_
    사전에 정리하여 브리프에 반영한 제품 특징과 USP를 이후 모든 브랜드
    생성 단계에 계속 전달하여 결 과물 사이의 일관성을 유지한다. 예를
    들어, 제품 특징·USP → 네이밍 → 선택된 브랜드명과 타깃 →
    슬로건·스토리 → 브랜드 컬러 → 브랜드명·컬러·제품 특징 → 로고 와 같이
    앞 단계의 결과를 다음 단계의 입력 정보로 활용한다. 이를 통해
    브랜드명, 슬로건, 스토리, 컬러, 로고가 각각 독립적으로 생성되는 것이
    아니라하나의 브랜드 콘셉트를 중심으로 서로 연결되도록 구성한다.

    수압 조절--- 사용자의 구강 상태와 선호도에 따라 세정 강도를 세밀하게

    모드와 잇몸 자극 및 마사지를 위한 마사지 모드를 제공한다. • 90초
    사용 가능한 물 용량--- 한 번 물을 채워 비교적 여유 있게 구강세정을

    맞는 팁을 제공한다. • 30초 페이서 및 1분 타이머--- 구강세정 시간을

    360도 회전 팁--- 팁의 방향을 조절하여 구강 내 필요한 부위에 접근할

    교체하는 방식으로 가족 구성원이 하나의 본체를 함께 사용할 수 있다.
    핵심 USP(차별화 포인트)

7.  프로그램 전체 실행 흐름 WP-670K 제품 특징 사전 정리 ↓ 타깃 고객 설정
    ↓ 브랜드 브리프 JSON 구성 ↓ 브랜드 브리프 파일 입력 및 검증 ↓ AI
    브랜드 네이밍 생성 ↓ 슬로건 생성 ↓ 브랜드 스토리 생성 ↓ 브랜드 컬러
    생성 ↓ 컬러 팔레트 PNG 시각화 ↓ AI 로고 시안 생성 ↓
    brand_result.json / PNG 결과 저장

파이프라인 설명 본 프로젝트에서는 WP-670K 제품 자료를 프로그램이 직접
읽어 자동 분석하는 방식이 아니라, 제품 자료에 서 확인한 주요 기능과
특징을 사전에 정리하여 브랜드 브리프 JSON에 반영하였다. 프로그램은
입력된 브랜 드 브리프의 제품 특징, 타깃, 키워드, 톤앤매너 등의 정보를
검증한 후 OpenAI API를 활용하여 브랜드 네이 밍, 슬로건, 브랜드 스토리와
컬러를 생성한다. 생성된 컬러 정보는 matplotlib을 이용해 컬러 팔레트
PNG로 시각화하며, 브랜드명·컬러·제품 및 타깃 정보를 이미지 생성 단계에
전달하여 로고 시안을 생성한다. 마지막 으로 텍스트 결과는
brand_result.json, 컬러 팔레트와 로고는 개별 PNG 파일로 출력 폴더에
저장한다.

직장인을 대상으로 했을 때는 클리오센스, 50\~60대 중장년층을 대상으로
했을 때 는 클린포커스가 생성되어 동일한 WP-670K 제품이라도 타깃에 따라
네이밍, 메시지와 컬러가 달라지는 것을 실제 결과를 통해 확인할 수 있었다.
또한 브랜드 브리프 입력값 검증, 기존 brand_result.json재사용, 로고 생성
여부 선택 등의 기능을 추가하여 프로그램의 안정성과 사용 편의성을 높이고
불필요한 API 호출을 줄일 수 있도록 하였다.

아쉬운 점/한계 제품 PDF의 모든 내용을 프로그램이 직접 읽고 자동 분석하는
구조까지는 구현하지 못했으며, 제품 자료에서 사전에 확인한 핵심 특징을
브랜드 브리프에 정리하여 활용하였다. 따라서 현재 구현은 제품 자료 자체를
AI 가 직접 분석하는 방식이 아니라 사전에 정리된 제품 특징을 AI가 브랜드
관점에서 해석하는 방식이라는 한계 가 있다. 또한 이미지 생성 AI의 특성상
로고 내부의 영문 철자가 정확하지 않게 생성되는 경우가 있었으며, 이를
확인 하고 수정하는 과정이 필요하였다. 이미지 API를 이용한 로고 생성에는
사용량에 따른 비용이 발생한다는 점 도 고려해야 한다.

추후 개선 방향 향후에는 제품 PDF나 제품 설명 파일을 프로그램이 직접
입력받아 주요 특징과 USP를 자동으로 추출하는 기 능을 추가할 수 있다.
또한 경쟁사 정보를 자동으로 수집·분석하여 자사 제품과의 차별화 요소와
브랜드 전략 까지 생성하도록 확장할 수 있다. 로고 생성 이후 브랜드명의
영문 철자를 자동으로 검사하는 기능과 여러 타깃의 생성 결과를 한 화면에서
비 교하는 기능을 추가한다면 프로그램의 정확성과 활용도를 더욱 높일 수
있을 것으로 생각한다.

제출 전 보안 점검 OpenAI API Key는 소스 코드에 직접 입력하지 않고
.env파일을 통해 환경 변수로 관리하였다. .env에는 실제 API Key가 저장될
수 있으므로 최종 제출용 압축파일에서는 반드시 제외한다. 가상환경인
.venv역시 용량이 크고 실행 환경에서 다시 생성할 수 있으므로 제출
대상에서 제외한다. 최종 제출용 프로젝트에는 main.py, requirements.txt,
.gitignore, briefs/, output/등 프로그램 실행과 결과 확 인에 필요한
파일을 포함하고, .env와 .venv는 포함하지 않는다.
